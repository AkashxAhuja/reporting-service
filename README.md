# Reporting service

A reporting service for concurrent date-range requests over a single MySQL table containing approximately 200 million rows across two years.

Start with the [high-level design](docs/high-level-design.md), which includes the architecture diagram, request flow, constraints, and assumptions. The [Mermaid diagram source](docs/diagrams/reporting-service.mmd) is editable and can be imported into a Mermaid-compatible diagram editor.

Current stage: architecture proposal. API implementation and low-level design follow after the reporting contract is defined.
